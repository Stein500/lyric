# Archives des images Vivi OOR

Les dix PNG de chaque version, les photos sources et les présentations locales sont conservés. Seuls les deux ZIP qui dupliquent ces PNG ont été retirés de l’arbre courant pour réserver la place au clip et au master audio. Les archives restent intégralement disponibles dans l’historique Git aux mêmes liens immuables déjà livrés. Contenu comparé octet par octet et présence vérifiée via l’API GitHub avant retrait.

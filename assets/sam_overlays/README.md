# Kit incrustation Sam

- `cta_pack.svg`: sticker CTA horizontal, transparent outside, thumbs bleu + cloche + textes.
- `typography_guide.svg`: références de police/couleurs.
- Police recommandée : DejaVu Sans Bold (titre), DejaVu Sans Regular (sous-texte).
- Couleurs : bleu cyan `#38BDF8`, bleu profond `#061227`, blanc `#FFFFFF`, accent rouge `#FF4567`.
- Ne pas incruster le CTA en continu : 0,6–0,9 s après le moment fort, puis disparition douce.
